# POLBAN_Academic_Console
Program dengan bahasa Python yang ditujukan untuk mengisi kehadiran melalui console terminal pada sistem akademik kampus POLBAN tanpa perlu mengakses melalui situs web [Akademik Polban](https://akademik.polban.ac.id/).
Program ini khusus untuk dijalankan di sistem operasi Linux

## Installation

Install dependensi:

```bash
python3 -m venv .venv
python3 -m pip install -r requirements.txt
source venv/bin/activate
```

Untuk menjalankan program:
```bash
python3 main.py
```
